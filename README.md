# 8-bit ALU - Verilog

8-bit ALU designed in Verilog - Supports ADD, SUB, AND, OR, XOR operations with Carry Out and Zero flag detection. Simulated and verified on EDA Playground using Icarus Verilog.

## Files
- alu.v - Design Code (ALU)
- tb_alu.v - Testbench Code

## Operations
| Sel | Operation |
| --- | --- |
| 000 | ADD |
| 001 | SUB |
| 010 | AND |
| 011 | OR |
| 100 | XOR |

## How to Run
1. Open EDA Playground
2. Select Icarus Verilog
3. Copy alu.v as Design and tb_alu.v as Testbench
4. Run and check waveform
